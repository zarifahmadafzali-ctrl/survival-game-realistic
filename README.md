# Stillwater

بازی اول‌شخص سه‌بعدی (دریاچه، کوه، گرگ، تفنگ).

## بازی آنلاین
https://zarifahmadafzali-ctrl.github.io/survival-game-realistic/

## دانلود APK
1. برو به تب **Actions**
2. workflow **Build APK** را باز کن
3. آخرین اجرا را باز کن
4. از **Artifacts** فایل `stillwater-apk` را دانلود کن
5. روی گوشی نصب کن

## اجرا محلی
```bash
npm install
npm run dev
```
